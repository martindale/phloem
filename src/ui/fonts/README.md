`gm-display-roman.woff2` is Fraunces (variable, SIL Open Font License 1.1, (c) The Fraunces Project Authors,
https://github.com/undercasetype/Fraunces), subset to Basic Latin plus a few punctuation marks, with the optical-size axis pinned
to 72 and SOFT=100, WONK=1; only the weight axis (300-600) is kept. Used for the wordmark, headlines and commit captions.

The license text is in `OFL.txt` next to the font (the OFL requires it to accompany the font); the build also serves it as `OFL-Fraunces.txt`. The font is not renamed and is not sold on its own.
